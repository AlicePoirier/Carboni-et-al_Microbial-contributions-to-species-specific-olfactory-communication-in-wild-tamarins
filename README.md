**README - Datasets for publication:**

Multiomic evidence for microbial contributions to species-specific olfactory communication in wild tamarins 

**Authors**: Carboni S, Poirier AC, Watsa M, Erkenswick GA, Melin AD


**File 1**: metadata_Odor_SampleList_Carboni-et-al_2026.csv

List of all samples used for VOC analyses.

Column titles:

* Sample: Sample barcode (common to microbiome data)
* UniqueID: Unique animal ID with year of sample collection
* OSample: Odor sample ID
* Year: Year of collection
* AnimalID: Unique animal ID
* Date: Date of sample collection
* Capture: Unique capture number
* Species: Tamarin species
* Group: Tamarin group
* Indiv: Tamarin individual


**File 2**: metadata_Odor_CompoundList_Carboni-et-al_2026.csv

List of all compounds retrieved from tamarin scent gland odor samples.

Column titles:

* Comp: Compound code
* CompName: Compound identity
* OSample: Odor sample ID
* RT: Retention time
* Area: Peak area
